## 一、项目介绍

PYAS Security Cyanmod 是 87owo/PYAS(Windows 开源杀毒)的中文增强分支。技术形态:**Python 3.14 + pywebview(WebView2)用户态杀毒**,全程策略模式(写配置经策略 broker 事务化提交),无内核驱动依赖(驱动防护为可选组件)。

- 构建:`py -3 build.py local`(dev 渠道)/ CI tag `v*` 触发自动发布(release);release 说明取仓库根 `RELEASE_NOTES.md`
- 测试:`py -3 -m unittest discover tests`(614 项;运行中的 PYAS 会干扰部分文件锁类测试,单跑消失即环境问题)
- 多语言:11 语言(繁中/简中/英/日/韩/法/西/印地/阿/俄/斯洛文尼亚);**动作列**由前端 i18n.js 查词(构建守卫 `test_log_action_i18n` 强制)、**详情列**写时本地化(集中表 `PYAS_LogTexts`,模块表 `ETW_LOG_TEXTS`/`BEHAVIOR_LOG_TEXTS`/`CANARY_LOG_TEXTS`)
- 策略契约:`pyas_default` 新增配置键必须登记 `PYAS_Policy` 对应桶(BOOL/STRING/NUMBER/LIST/USER),守卫 `test_policy_config_keys`
- 本机体验包:版本号 3.7.1-20 发布于 10-27;21→32 系列在本地(30 起含蜜罐/AMSI),推送与发布需用户批准

## 二、已完成功能(按域)

**拦截与检测**
- 拦截弹窗队列:文件/进程告警合并单窗、永久/临时/仅本次三档、内容锚定误报抑制(SHA256×90 天)、误报一键解释入口、AI 建议按钮(本地/云端模型,DPAPI 加密存钥,TTL 缓存)
- 扫描引擎:YARA 规则 + PE ML 模型(onnx)+ **AMSI 脚本内容通道**(消费本机 AMSI provider,JS/VBS/PS1 等前置判定,fail-open 到自有引擎)
- **勒索三防线**:①突发启发(pre-existing 30 秒窗 + 程序区域段名判定 + 签名×安装树绑定豁免 + Temp 例外,递进收窄防对抗)②**蜜罐文档**(桌面/文档隐藏诱饵 docx,随机中性正文无指纹,声明写 NTFS ADS,同进程冷却,命中即告警+自动回滚挂钩,巡检换新补种)③卷影完整性轮询(在册卷影被外部删除即告警——勒索破坏回滚的前置动作)

**溯源与取证**
- ETW Kernel-File 自研消费者(ctypes,零驱动):NameCreate/Create→FileKey/FileObject 关联表(65536 条/300s)→Write 反查归属;关联表与溯源缓存(300s/16384)容量按真实弹窗链路(写入→防抖→扫描→用户裁决 ~90s)校准并契约锁下限
- 溯源 miss 诊断:查询未命中记 peek(该路径是否曾记录/记录时长/层规模),一次复现定位断点;消费 probe(10s/30s)细分 no_key/双 miss/attribution 层状态
- 事件审计页(勒索启发/卷影/回滚/智能体提权过滤)+ 「回滚此进程」一键回滚

**卷影与恢复**
- VSS 紧急快照:CIM+WMI v1 双路创建(客户端 SKU 可用),Python 侧 vssadmin 解析设备名(重试),每卷保留 N 份历史(默认 3,可调),并发护栏,孤儿清理
- 卷影备份页:卷条目(盘符/创建时间/份数/占用比例条)、文件浏览+当前目录搜索+勾选恢复原位、签名门下错误可见化(非提权直接说明原因)

**权限与体验**
- 特权运行闭环:开关默认开,启动核对自动恢复+提权重启(helper 代发,单次 UAC);说明弹窗(主窗内模态+「以后自动申请」勾选记忆);安装器「以管理员身份运行」勾选;快捷方式 SLDF_RUNAS_USER 自动打标闭环
- 托盘通知点击→主界面+跳审计页;拦截弹窗高度自适应/队列空态收起;主窗 DWM 原生动画;窗口缩放/拖拽;经典+Win11 右键菜单双路;自启动(注册表+计划任务提权双路)
- 界面:11 语言全量(含日志详情)、图标集重绘护栏测试、蜜罐/诱饵开关等 UI

## 四、关键操作与陷阱(移交必读)

- **Edit 工具锚点跨方法签名会静默删码**(fef4443/多轮教训):改完必跑对应测试文件
- **heredoc 写补丁不可靠**(CRLF/转义):多行修改用 Write/Edit 工具
- **多会话并行常态**:动手前 grep 现状,勿基于旧快照打补丁;外部会话产出的未跟踪文件会被 add -A 扫入
- **发布流程**:main 推送 → tag v* → CI 全自动(见 `github-proxy-setup` 记忆:直连/代理按时刻漂移,失败换路;Steam++ 在 `C:\Program Files\Steam++\Steam++.exe`,未运行时 Start-Process 拉起)
