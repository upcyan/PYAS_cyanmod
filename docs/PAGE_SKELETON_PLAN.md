# 页面骨架统一 · 实施计划

> 目标:14 个页面用同一套「标题区 / 工具条 / 内容区」骨架,逐页套用、逐页验收、随时可停。
> 约束:**配色、圆角、阴影、控件高度全部沿用现有令牌**;不改后端、不改 `renderDataGrid` 契约。

## 一、骨架分型(实测自 `index.html`)

| 型 | 结构 | 页面 | 说明 |
|---|---|---|---|
| **A** | `.sub-header-toolbar` + `.manage-widget` | 隔离区、放行记录、进程、启动项、白名单、垃圾、修复、弹窗规则、网络、自定义防护、日志导出(11 页) | 工具条内含返回键、标题、搜索、动作下拉 |
| **B** | `.page-head` + `.list-widget` | 防护、工具、设置、AI、关于(5 页) | 本轮补了 `.page-head` 标题区 |
| **C** | `.progress-widget` + `.scan-content` | 病毒扫描(1 页) | 标题+描述+扫描方式 |
| **特** | 自定义 | 首页 | 已单独重构(状态区+卡片+日志) |

## 四、每页验收清单(逐页打勾)

1. 标题区:标题 20/600,与内容区左边缘对齐;
2. 工具条:控件同高 40,基线与标题同轴,窄窗口(720px)不换行错位;
3. 内容区:可滚动且**只有一层**滚动条;卡片圆角 12、投影 shadow-1;
4. 空态:空数据时不留"光表头";
5. 键盘:Tab 顺序经过工具条 → 列表,焦点环可见;
6. 主题:白/黑主题切换后无死黑、死白。

> 现状短板:`.col-header` 是 sticky + `z-index:10`,任何盖在网格上的浮层都要 ≥11 或直接隐藏表头(扫描页踩过)。

## 五、风险与回滚

- 风险 1:标题字号统一后,长标题(如"隔离区管理")在 720px 最小宽度下可能挤压右侧控件 → 用 `white-space: nowrap` + 允许搜索框收缩。
- 风险 2:`.page > .list-widget` 改 `flex:1` 后,内容多的列表可能出现双滚动 → 每页必须验证。
- 回滚:改动集中在 `index.html`(4 处标题 + 1 处空态)与 `style.css` 末尾两块;`git checkout -- <file>` 即可,无数据迁移。

**关键修复(不在原计划内,但必须先做)**

> `.list-widget` 是 `height:100%` 的纵向 flex,子项默认 `flex-shrink:1`。内容超出容器时
> **行会被压扁而不是滚动**,开关滑块被 `.settings-group{overflow:hidden}` 裁掉,点击命中组容器。
> 修法:`.list-widget > * { flex-shrink: 0 }`。不做这一步,任何"变矮"的排版改动都会碎点击区。
