# PYAS 界面规范(2026-10 版)

给"改界面的人"看的一份约定。所有条目都在真实代码里踩过并验证过,不是设想。

---

## 一、令牌

| 类别 | 令牌 | 值 | 用途 |
|---|---|---|---|
| 控件高度 | `--control-height` | 40px | 按钮 / 输入框 / 下拉 |
| 圆角 | 6 / 8 / 12 / 999 / 50% | 5 档 | 控件 / 卡片 / 面板 / 胶囊 / 圆 |
| 字号 | `--text-2xs`…`--text-5xl` | 11–24px | 见下表 |
| 图标 | 20px 画形 / 32px 命中 | — | `.icon-btn` `.icon-action-btn` |

字号用法:
- 窗口标题 `--text-2xl`(17)
- 页面标题 `--text-3xl`(19),**不随窗口缩放**(早期用 `clamp()` 到 24,和 14px 副标题并排时像没对齐)
- 卡片标题 `--text-md`(14) / 说明 `--text-xs`(12)
- 表格单元格 13,副标题与时间列 12

## 二、三型骨架

**A 型(列表页)**: `.page-head`(返回 + 标题 + 分隔 + 摘要 + 搜索/动作) → `.manage-widget`(吸顶表头 + 行)

**B 型(设置/关于类)**: `.page-head` → `.list-widget`(纵向 flex,**子项必须 `flex-shrink: 0`**)

**C 型(扫描页)**: `.page-head` → `.scan-content` → 自定义空态(带引导按钮)

> 空态统一由 `initGridEmptyStates()` 驱动:无数据时插 `<li class="manage-list-empty">`,
> 表头 `visibility: hidden`,文案在容器内垂直居中。扫描页用它自己的(有"智能扫描"入口)。

---

## 三、动作条(`.action-group`)

- 选中 0 行时有**页面级动作**的页(白名单/隔离区/放行记录) → 显示"新增文件 / 新增路径";
- 选中 0 行且**没有**页面级动作的页(启动项/进程/修复/网络/日志导出) → 行动作**常驻但置灰**
  (`opacity:.45; cursor:not-allowed`)。空白会比置灰更糟:用户以为这页没有操作;
- 选中 ≥1 行 → 显示批量动作 + 右侧摘要,摘要里的"取消选择"与表头全选框同源。

---

## 四、告警弹窗

**结构**(自上而下,单面 + 发丝线,**不套卡片**):
标题/摘要 → 判断原因(四字段 + 命中规则 + 详细原因)→ 文件区块(文件 / 文件 SHA-256 / 目标 / 发起进程)
→ 原始事件文本(默认收起)→ AI 辅助决策 → 状态行 → 动作条。

**按钮语义**:

| 按钮 | 外观 | 行为 |
|---|---|---|
| 永久允许 | 白底描边 | 写 allow 规则,需二次确认 |
| 本次允许 | 主色实心 | 只放行这一次 |
| 永久拦截 | 白底描边 | `decide('block', true)`,写阶梯重复规则,**不是真永久** |
| 本次阻止 | 危险色实心(默认) | `decide('block', false)`,只处理这一次 |

排布:左组 [永久允许][本次允许],右组 [永久拦截][本次阻止];倒计时数字只挂在**本次阻止**上。

> 按钮的可访问名固定为动作词(`aria-label`),倒计时数字只是视觉提示,读屏与自动化不受影响。

## 五、主题

- `theme.js` 把**主题键名**写到 `document.documentElement.dataset.theme`(如 `black_switch`);
  CSS 选择器必须写全名。写成 `[data-theme="black"]` 会**静默失效**:
  高光仍 22%、发丝线仍是黑色 → 侧栏发灰、标题栏下缘出现突兀亮线。
- 暗色材质三件套:`--material-sheen`(≤6%)、`--material-edge`、`--material-hairline`,
  全部定义在 `[data-theme="black_switch"]` 里。
- 暗色窗口底色 `18,18,20`(不是纯黑),面板 `32,32,35`,导航 `28,28,30`。

## 六、已知坑(改之前先读)

1. **纵向 flex + `height:100%` 的容器**,子项默认 `flex-shrink:1`,
   内容超高时**行被压扁而不是滚动**,`overflow:hidden` 会把开关滑块裁掉 → 点击命中容器。
   必须 `.list-widget > * { flex-shrink: 0 }`。
2. **开关滑块是绝对定位**(`.slider{position:absolute;inset:0}`),外层 `overflow:hidden` 的组容器
   一旦裁剪它,Playwright 会报 `settings-group intercepts pointer events`。
3. **中文字身比 em 盒高**:20px 中文墨迹约 27px。判断"文字有没有对齐"要量**墨迹**,
   量盒子会得到"完全对齐"的错误结论。`align-items: baseline` 会把大字顶上去,别用。
4. **CSS 变量名 / JS 键名不一致 = 静默失效**,视觉上只表现为"哪里有点怪",不会报错。
5. `.col-header` 是 `sticky + z-index:10`,任何浮层要 ≥11 或直接隐藏表头。
6. 弹窗消息里 `来源/目标/进程` 与结构化行重复,展示前按行剔除(见 `normalizeEventText` 的历史版本)。
